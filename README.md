# discord-oneclick

DiscordのWebブラウザ画面上から、元画像やメディア情報を一括抽出・管理するためのTampermonkey UserScriptです。

## 主な機能
* スレッドやチャンネル内のメディアURL（元画像等）の抽出・リスト化
* **階層フォルダ保存**: サーバー名 / チャンネル名 / スレッド名（スレッドID付き）の階層フォルダを自動作成し、整理された状態でダウンロード可能
* 抽出データのCSV / SQLite / JSON エクスポート機能
* 重複ファイルのトラッキングとモーダルダイアログによる詳細表示
* 画面上の画像コンポーネントに対する「保存（Save）」ボタンの直接インジェクト

## インストール
Tampermonkeyなどの拡張機能に `*.user.js` を追加して使用します。
## 導入前後の違い（メリット）

本スクリプトを導入することで、Discordの標準仕様にはない以下の強力なメリットが得られます。
* **ワンクリック階層保存**: 「サーバー名/チャンネル名/スレッド名」のフォルダ階層が自動生成され、手動でのファイル整理の手間がゼロになります。
* **警告メッセージのスキップ**: ZIPファイルなどの画像以外のファイルをダウンロードする際、ブラウザ版Discord特有の「このファイルは危険な可能性があります」という警告モーダルをバイパスし、即座に直接ダウンロードが始まります。
* **ファイル名の最適化**: Shift_JIS非対応の特殊文字や絵文字による文字化け（文字消失）を未然に防ぐ、古いWin32アプリ互換のファイル名化機能（クレンジング）が自動適用されます。

## ダウンロード履歴（DB）について

本スクリプトは、重複ダウンロード防止機能と「✔ 済」表示のために、ダウンロード履歴をデータベースとして保持しています。

* **保存場所**: 
  履歴データは、ご利用のブラウザ拡張機能（Tampermonkey）の内部ストレージ（拡張機能専用のセキュアなローカル領域）に保存されます。
* **バックアップと他OSへの移行（リストア）**: 
  可能です。Tampermonkeyのダッシュボード設定にある「ユーティリティ」タブから、スクリプトとストレージデータを丸ごとZIPエクスポートできます。Windowsを再インストールした際や、Mac等の別OSへ移行する際も、そのファイルを新しい環境にインポートするだけで完全に履歴を引き継ぐことができます。
* **手動エクスポート機能**:
  スクリプトのメニュー（⚙️アイコン）から、CSV形式やSQLite用のSQL形式での履歴の書き出し、およびJSONバックアップが可能です。

## 詳細な導入方法

1. お使いのブラウザ（Chrome / Edge 等）に、拡張機能 **[Tampermonkey](https://www.tampermonkey.net/)** をインストールします。
2. 本リポジトリの \discord-oneclick.user.js\ の内容をコピーし、Tampermonkeyのダッシュボードの「新規スクリプトを追加」タブに貼り付けて保存します。
3. DiscordのWeb版を開き直す（リロードする）と、自動的にスクリプトが有効になります。

## バージョン履歴 (Changelog)

- **v1.x - v2.x**: 初期リリースおよび履歴DB機能の追加。ワンクリック階層保存（サーバー/チャンネル/スレッド）と重複ダウンロード防止を実装。ファイル名の衝突防止のためタイムスタンプ付与を追加。
- **v3.0.x - v3.3.x**: \
ame2win\ 互換のファイル名サニタイズ（NFC正規化、macOS不可視文字除去、丸数字や記号の集約）を組み込み。
- **v3.4.x - v3.5.x**: DiscordのSPA（React）特有のレイアウトハイドレーション（再レンダリング）に対応するため、実行タイミングの調整とグローバルCSSインジェクトを導入。動的に開いたスレッドやモザイクレイアウトでの「Save」ボタン見切れ・消失バグを完全解消。
- **v3.6.0 - v3.6.2**: 「クレンジング」表記を「古いWin32アプリ互換ファイル名化」に改称。Tampermonkeyのメニューから直接「1. 日付_ファイル名」「2. ファイル名_日付」「3. ファイル名のみ（日付なし）」のファイル名書式を1クリックで切り替えられるラジオボタン式設定UIを追加。
