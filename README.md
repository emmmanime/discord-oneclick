# discord-oneclick

**Version 3.7.0 (2026-10-13)**

DiscordのWebブラウザ画面上から、元画像やメディア情報を一括抽出・管理するためのTampermonkey UserScriptです。

## 主な機能
* スレッドやチャンネル内のメディアURL（元画像等）の抽出・リスト化
* **階層フォルダ保存**: サーバー名 / チャンネル名 / スレッド名（スレッドID付き）の階層フォルダを自動作成し、整理された状態でダウンロード可能
* **ファイル名書式の選択**: 「日付_ファイル名」「ファイル名_日付」「ファイル名のみ」から選択可能
* 抽出データのCSV / SQLite / JSON エクスポート機能
* 重複ファイルのトラッキングとモーダルダイアログによる詳細表示
* 画面上の画像コンポーネントに対する「保存（Save）」ボタンの直接インジェクト

## 導入前後の違い（メリット）

本スクリプトを導入することで、Discordの標準仕様にはない以下のメリットが得られます。
* **ワンクリック階層保存**: 「サーバー名/チャンネル名/スレッド名」のフォルダ階層が自動生成され、手動でのファイル整理の手間がゼロになります。
* **警告メッセージのスキップ**: ZIPファイルなどの画像以外のファイルをダウンロードする際、ブラウザ版Discord特有の「このファイルは危険な可能性があります」という警告モーダルをバイパスし、即座に直接ダウンロードが始まります。
* **ファイル名の最適化**: Shift_JIS非対応の特殊文字や絵文字による文字化け（文字消失）を未然に防ぐ、古いWin32アプリ互換のファイル名化機能（クレンジング）が自動適用されます。

## 動作要件

| 項目 | 要件 |
|---|---|
| ブラウザ | Chrome / Edge / Brave などの Chromium 系ブラウザ |
| 拡張機能 | [Tampermonkey](https://www.tampermonkey.net/) 5.5.1 以降で動作確認 |
| Discord | Web版（`https://discord.com/`） |

## 詳細な導入方法

1. お使いのブラウザに、拡張機能 **[Tampermonkey](https://www.tampermonkey.net/)** をインストールします。
2. **ユーザースクリプトの実行権限を有効にします**（下記「⚠️ 初回設定」の 1 を参照）。
3. 本リポジトリの `discord-oneclick.user.js` の内容をコピーし、Tampermonkeyのダッシュボードの「新規スクリプトを追加」タブに貼り付けて保存します。
4. DiscordのWeb版を開き直す（リロードする）と、自動的にスクリプトが有効になります。
5. 初めて「保存」ボタンを押した際に表示される**ダウンロード権限の要求を「許可」**します（下記「⚠️ 初回設定」の 2 を参照）。

## ⚠️ 初回設定（Tampermonkey 5.5 以降）

### 1. ユーザースクリプトの実行権限（Tampermonkey 5.5.1 以降で必須）
Tampermonkey 5.5.1 から、ユーザースクリプトをページに注入するために**ブラウザ側の特別な権限**が必要になりました。
これを有効にしないと、**「保存」ボタンが一切表示されず、スクリプトが動作しません。**

* ブラウザの拡張機能管理画面 → Tampermonkey の「詳細」→ **「ユーザースクリプトを許可」をオン**にします。
* ブラウザにより表記・手順が異なります。詳細は [Tampermonkey 公式の変更履歴（v5.5.1）](https://www.tampermonkey.net/changelog.php) 内の案内リンクを参照してください。

### 2. ダウンロード権限（Tampermonkey 5.5.0 以降）
Tampermonkey 5.5.0 から、スクリプトによる保存・ダウンロードの際に**オプションのダウンロード権限**が要求されるようになりました。
初回の「保存」時に表示されるダイアログで**「許可」**を選択してください。

> [!WARNING]
> **Download Mode を「Native」に変更しないでください。**
> Tampermonkey の変更履歴には「Download Mode を Native にすれば権限要求を無効化できる」と記載されていますが、Native モードは**サブフォルダを含む保存先に対応していません**。
> 本スクリプトの階層フォルダ保存（`Discord/サーバー名/チャンネル名/...`）が機能しなくなるため、Download Mode は **「Browser API」** のままにしてください。
> （設定場所: Tampermonkey ダッシュボード → 設定 → 設定モード「上級者」→ ダウンロード BETA → Download Mode）

## 💡 推奨するブラウザ設定（Chromium系）

本スクリプトの「ワンクリック保存」を最大限に活かすため、ブラウザの設定画面（`chrome://settings/downloads` や `brave://settings/downloads` 等）から、以下の設定をあらかじめ行っておくことを強く推奨します。

* **「保存先」でファイルを保存したいフォルダーを指定する**
  Windowsシステムドライブ（Cドライブ）の容量枯渇を防ぎたい場合や、すでにDiscord用のファイル整理場所を決めている場合に有効です。本スクリプトで作成される `Discord` フォルダは、ここで指定したフォルダの直下に作成されます。
* **「ダウンロード前に各ファイルの保存場所を確認する」のチェックを外す（オフにする）**
  この設定がオンになっていると、保存ボタンを押すたびに保存先を尋ねるダイアログが発生してしまいます。オフにすることでユーザーへの問い合わせが発生せず、連続してファイルをスムーズにダウンロードできるようになります。

## 制限事項

* **保存先のルート**: ブラウザ（Tampermonkey）の仕様上、ブラウザの既定の「保存先（ダウンロードフォルダ）」の外へ直接保存することはできません。任意の場所に保存したい場合は、上記の「推奨するブラウザ設定」の通りにブラウザ自体の保存先を変更してください。
* **他の拡張機能との競合（ファイル名・階層の阻害）**: 画像ダウンローダー系や保存管理系の拡張機能（例: Image Downloader 等）を併用している場合、Chromiumの仕様（ダウンロード処理の排他制御）により、本スクリプトによるファイル名生成やフォルダ階層の作成処理が阻害・上書きされる場合があります。この現象が発生した場合は、該当する拡張機能の管理画面（`chrome://extensions` や `brave://extensions` の「詳細」）にて、「サイトへのアクセス」を「クリックされた場合のみ」に変更するか、ダウンロードを行うサイト（Discord）を除外対象に設定してください。
* **保存に失敗した場合**: 階層フォルダでの保存に失敗した場合、フォルダ区切りを `_` に置き換えたフラットなファイル名での保存を自動で再試行します。失敗の原因（権限不足・Download Mode 等）はアラートとブラウザの開発者ツール（Console）に表示されます。

## ダウンロード履歴（DB）について

本スクリプトは、重複ダウンロード防止機能と「✔ 済」表示のために、ダウンロード履歴をデータベースとして保持しています。

* **保存場所**:
  履歴データは、ご利用のブラウザ拡張機能（Tampermonkey）の内部ストレージ（拡張機能専用のローカル領域）に保存されます。
* **バックアップと他OSへの移行（リストア）**:
  可能です。Tampermonkeyのダッシュボード設定にある「ユーティリティ」タブから、スクリプトとストレージデータを丸ごとZIPエクスポートできます。Windowsを再インストールした際や、Mac等の別OSへ移行する際も、そのファイルを新しい環境にインポートするだけで履歴を引き継ぐことができます。
* **手動エクスポート機能**:
  Tampermonkeyのメニューから、CSV形式やSQLite用のSQL形式での履歴の書き出し、およびJSONバックアップが可能です。

## バージョン履歴 (Changelog)

- **v1.x - v2.x**: 初期リリースおよび履歴DB機能の追加。ワンクリック階層保存（サーバー/チャンネル/スレッド）と重複ダウンロード防止を実装。ファイル名の衝突防止のためタイムスタンプ付与を追加。
- **v3.0.x - v3.3.x**: Shift_JIS / Windows 互換のファイル名サニタイズ（NFC正規化、macOS不可視文字除去、丸数字や記号の集約）を組み込み。
- **v3.4.x - v3.5.x**: DiscordのSPA（React）特有のレイアウトハイドレーション（再レンダリング）に対応するため、実行タイミングの調整とグローバルCSSインジェクトを導入。動的に開いたスレッドやモザイクレイアウトでの「Save」ボタン見切れ・消失バグを解消。異体字セレクタ（`U+FE0E`, `U+FE0F`）の除去を追加。
- **v3.6.0 - v3.6.2**: 「クレンジング」表記を「古いWin32アプリ互換ファイル名化」に改称。Tampermonkeyのメニューから「1. 日付_ファイル名」「2. ファイル名_日付」「3. ファイル名のみ（日付なし）」のファイル名書式を1クリックで選択できるラジオボタン式設定UIを追加。
- **v3.7.0**: 幾何学図形絵文字（三角、ダイヤ、丸）の標準集約を追加。Shift_JIS外だが古のWin32アプリ（MangaMeeya等）で安全に扱える伝統的BMP記号（`♥`, `♡`, `♬`, `♠`, `♣` 等）の保護を実装。
- **v3.7.1**: ハート系絵文字（`💕`, `💛` 等）の集約先記号を、より自然で標準的な白ハート（`♡`）へ変更（`♥` も保護対象として維持）。
